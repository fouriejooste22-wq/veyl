Interface Reference / Aurelia

The design specification the UMG widgets are built from. Nine screens, fifteen provinces, a confrontation ladder running to a final antagonist, and four difficulty presets whose values are the ones in FShadowlineDifficultyKnobs::FromPreset.

This is a design reference, not the game. It is a web mockup used to settle layout, hierarchy and interaction before any widget is built in Unreal. The game itself is UE5 and has never been compiled.

The images are concept art, not screenshots. They are drawn procedurally in the browser to establish each region's light and silhouette. Nothing has been rendered in an engine yet, so no real capture exists to show.

Where this fits. Stage 2 of ten. These screens become WBP_* widgets under Content/Shadowline/UI/, driven by CommonUI so gamepad and mouse both work without separate layouts. The province, mission and difficulty data behind them is already authored as C++ data assets: UShadowlineProvinceDefinition, UShadowlineMissionDefinition, UShadowlineDifficultyProfile.

Original IP. Aurelia, Threshold, Vantrell Continental and every person named here are invented for this project. The structure borrows genre conventions — provinces, intel gathering, a named target per province — but no name, mark, mission, character or interface design is taken from any existing game.

Non-lethal by design. Threshold has no weapons and no authority to use force. A confrontation is resolved by getting a target on record, lifting their drive, or putting them on a boat. There is no death screen in this game, and a detection escalates a situation rather than ending it.
