Operation Shadowline · Stage 2 pre-production

Interface Reference / Aurelia

The design specification the UMG widgets are built from: six screens, the information each one carries, and the behaviour each one commits to. Every value shown is drawn from the project's own data — the five regions, the squad, the five acts, and the real scalability groups in DefaultScalability.ini.

This is a design reference, not the game. It is a web mockup used to settle layout, hierarchy and interaction before any widget is built in Unreal. The game itself is UE5 and has not been compiled — see DEVELOPMENT_LOG.md. Nothing here ships.

Main menu

WBP_MainMenu

The first thing anyone sees, so it carries the operation's current state rather than a static splash: which act, which region, what the weather is doing, how much of Aurelia has been surveyed. Continue is the default focus.

Where this fits. Stage 2 of ten. The screens above become WBP_* widgets under Content/Shadowline/UI/, driven by CommonUI so a gamepad and a mouse both work without separate layouts. Nothing in this page is Unreal code; it is the agreed target that the widgets are measured against.

Original IP. Aurelia, Threshold, Vantrell Continental and every person named here are invented for this project. No names, marks, mission titles or interface designs are taken from any existing game.
